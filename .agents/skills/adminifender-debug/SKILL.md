# Debug

Read `AGENTS.md`, the relevant contract and smallest relevant source/test paths. Preserve unrelated changes. Do not read credentials, personal mail or archive data into context; do not delegate without explicit user request.

Collect the failing command, sanitized output, build variant, device/API or Worker environment and schema/model versions. Reproduce with a synthetic fixture where possible; consider competing hypotheses before editing. Fix only within the authorized task, then rerun the reproduction and focused regression checks. Preserve the original evidence and report remaining live/device uncertainty. Never weaken auth, exact review or test thresholds to hide failure.
